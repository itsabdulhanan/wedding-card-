# Royal Wedding Invitation Web Application 💍✨

A luxury, interactive digital wedding invitation application built with **React**, **Vite**, and **Tailwind CSS**.

## ✨ Features
- 👑 **Hero Royal 3D Door Reveal** with cinematic intro video and tap-to-open gesture
- 🎶 **Floating Glassmorphic Music Player** with track switcher, animated frequency visualizer, and custom wedding music
- ⏳ **Live Countdown Timer** with real-time conversion breakdown (Days, Total Hours, Total Minutes, Total Seconds)
- ✨ **Interactive Gold Foil Scratch Card** revealing the save-the-date message
- 📅 **Save the Date Calendar Integration** (Google, Outlook, Apple / .ics download)
- 🖼️ **Photo Slideshow Gallery**
- 🕌 **Ceremonies & Timeline** (Mehndi, Sacred Nikkah, Walima Reception at Qasar-e-Noor)
- 👗 **Dress Code & Travel Accommodation Details**
- 💌 **RSVP & Live Wishes Wall**
- 🎛️ **Live Customizer Drawer** for dynamic real-time personalization

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
